# Forkop для МТС Домашний Центр HC-001

Установщик **Forkop 1.0.5 + sing-box 1.12.0** для МТС Домашний Центр HC-001 под OpenLumi 23.05.4.

> ⚠️ Установщик предназначен для HC-001 с архитектурой ARM Cortex-A7.

## 📦 Что устанавливается

Установщик автоматически устанавливает:

- **Forkop 1.0.5**
- **LuCI App Forkop 1.0.5**
- **Русскую локализацию Forkop**
- **sing-box 1.12.0**
- необходимые зависимости через `opkg`

## 💻 Требования

Поддерживается:

| Параметр | Значение |
|---|---|
| Устройство | МТС Домашний Центр HC-001 |
| Прошивка | OpenLumi 23.05.4 |
| Target | `imx/cortexa7` |
| Архитектура | `arm_cortex-a7_neon-vfpv4` |

Устройство должно иметь доступ в интернет и SSH-доступ с правами `root`.

## 🚀 Установка

Подключитесь к HC-001 по SSH и выполните одну команду:

```sh
wget -O - "https://raw.githubusercontent.com/maksimhalutin-glitch/forkop-hc001/main/forkop%20hc001/install.sh" | sh




Установщик автоматически:

Проверит права root.
Определит установленную систему.
Проверит архитектуру устройства.
Проверит imx/cortexa7.
Выполнит opkg update.
Скачает Forkop 1.0.5.
Установит Forkop.
Установит LuCI App Forkop.
Установит русскую локализацию.
Скачает sing-box 1.12.0.
Установит sing-box.
Включит Forkop при загрузке.
Перезапустит Forkop.
Проверит результат установки.
🔎 Проверка установки
Forkop
forkop show_version

Ожидаемый результат:

1.0.5
sing-box
sing-box version

Должна быть установлена версия:

1.12.0
Состояние Forkop
forkop get_status

При нормальной работе:

{ "running": 1, "enabled": 1, "status": "running & enabled", "dns_configured": 1 }
🌐 LuCI

После установки откройте веб-интерфейс OpenLumi/LuCI роутера.

В интерфейсе появится раздел Forkop.

Дальнейшая настройка Forkop выполняется через LuCI.
